Cara pasang

  1. Buka di Chrome. Jangan lewat browser dalam aplikasi (WA/IG) — unduhan sering terblokir.
  2. Tap “Unduh APK”. Kalau Chrome memperingatkan “file berbahaya”, pilih Tetap unduh.
  3. Instal. Buka berkas yang terunduh, izinkan sumber tidak dikenal bila diminta, lalu Instal.
  4. Login. Pakai NBP / No. WhatsApp + PIN. Aplikasi selalu memuat versi web terbaru.

Catatan

  • APK ini Trusted Web Activity — pembaruan tampilan & fitur web muncul otomatis tanpa instal ulang.
  • Butuh Android 5.0+ dan Google Chrome.
  • Instal versi baru tanpa uninstall, selama tanda tangan APK-nya sama.
  • Kalau unduhan di sini bermasalah, pakai cadangan: GitHub Release.
  • Verifikasi berkas (SHA-256) __SHA256__
